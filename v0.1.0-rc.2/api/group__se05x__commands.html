◆ IsIrreversible()

constexpr bool se05x::IsIrreversible ( Command  command)
constexprnoexcept

Whether a command cannot be undone (S-10): lifecycle locks, feature changes, DeleteAll.

Device::Execute<> refuses these at compile time; they run only through irreversible:: with a confirmation, and only when the library is built with SE05X_ENABLE_IRREVERSIBLE.

Parameters
commandThe command.
Returns
true for an irreversible command; false for anything else, a non-enumerator included.
