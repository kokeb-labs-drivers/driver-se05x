Detailed Description

The error model of the SE05X driver: Error, Detail, Result<T>.

Frozen contract (see docs/contract.md): a change here is a breaking change and goes through the contract amendment rule in docs/builders.md. Every call of every layer returns an Error inside a Result. NotInitialized wins over InvalidArgument; InvalidArgument sends nothing; the raw status word of the chip is in Detail only. One status word maps to different errors by command context (SW 0x6985 after CloseSession without a session is NeedsReselect, not ConditionsNotSatisfied).
