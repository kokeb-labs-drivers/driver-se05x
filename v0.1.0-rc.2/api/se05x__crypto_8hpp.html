Detailed Description

ReferenceCrypto: the crypto port for tests and for bring-up on platforms without a crypto library.

Copyright
Copyright (c) 2026 The driver-se05x authors. SPDX-License-Identifier: MIT

ReferenceCrypto satisfies CryptoPort: AES-128, -192 and -256 (FIPS 197), AES-CBC (SP 800-38A), AES-CMAC (SP 800-38B), SHA-1 and SHA-2 (FIPS 180-4), and NIST P-256 key generation, ECDH and ECDSA with RFC 6979 nonces. It holds keys in a fixed table of kSlots entries behind KeyRef handles; ReleaseKey and the destructor wipe them (S-01). The building blocks live in se05x::refcrypto so the known-answer tests can reach them.

Bring-up only (S-15). The table lookups of AES are masked scans and the P-256 ladder has no branch on a secret bit, but nothing here is hardened against power analysis or fault injection, and the key table is ordinary RAM. Do not provision a real key with it: a production port wraps a hardware engine or a vetted library (mbedTLS, PSA) behind the same hooks. Random() needs an entropy source given at construction; without one it fails and so does GenerateP256().

Owner decision 5 (ship it in the library or keep it test-only) is recorded as an assumption: it ships, behind its own header, and nothing else in the library includes it.
