Detailed Description

The commands of the IoT applet: one enumerator per command, its group, its name and the CommandSet bitset.

Frozen contract. The enumerators are contiguous from 0 (EnumLast<Command>), so a table indexed by Command is checked with static_assert against kCommandCount. The order is the order of docs/datasheet.md (applet specification AN12413 section 4, applet 7.x commands appended to their group). The GlobalPlatform card manager commands are not in this list: they live in gp::. PAKE and T4T are held (ambiguity A6): they have no enumerator until their byte layout is sourced.

This file was generated once from a table and is maintained by hand afterwards: a new command is a contract amendment (an enumerator, a name, a group, a CommandTypes entry in se05x_device_types.hpp and a Codec specialisation).
