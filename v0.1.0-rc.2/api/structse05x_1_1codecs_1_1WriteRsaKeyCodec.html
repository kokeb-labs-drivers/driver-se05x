Detailed Description

WriteRsaKey: an externally generated key takes one APDU per component (AN12543 4.7.1.2): Step(args, 0) carries the key type in P1, the policy, the id, the size and the first component; each next step the id and one more component, in TLV order (TAG_3 to TAG_10). P2 is P2_RAW for a key in the private-exponent form and P2_DEFAULT otherwise, on every step (the middleware does the same). Encode is Step(args, 0); the device sends Steps(args) APDUs.
