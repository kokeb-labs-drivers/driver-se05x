Detailed Description

CRC16 of the T=1 frames.

Copyright
Copyright (c) 2026 The driver-se05x authors. SPDX-License-Identifier: MIT

Frozen surface: Crc16(). CRC-16/X-25: initial value 0xFFFF, reflected polynomial 0x8408, final XOR 0xFFFF, computed over NAD, PCB, LEN and INF (UM11225 section 2.1.3 p. 9; GPC_SPE_172 section 4.2.5 p. 36, which keeps the two-byte CRC of ISO/IEC 7816-3). The function returns the CRC as a number; the byte order on the wire is the link's business:

  • GP flavour: most significant byte first (GPC_SPE_172 section 4.2 p. 33, example CRC 0xBDA4, vector V7).
  • NXP flavour: UM11225 says only "CRC-1, CRC-2" (Figures 4 and 7, pp. 13 and 16). The link accepts either order on the first valid frame of Open() and then keeps that order (ambiguity A10); the order it tries first is least significant byte first, the order of the NXP Plug and Trust middleware, which the tests use as an oracle only (never a dependency).
