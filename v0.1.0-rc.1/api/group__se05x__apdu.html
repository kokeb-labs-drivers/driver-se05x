uint16_t  sw 
)
constexprnoexcept

Map a status word to an Error in the context of a command.

The same word maps differently by command: any word but 0x9000 after CloseSession is NeedsReselect (AN12543 4.5.1.5: the applet must be selected again; errata APP.2); 0x6985 is AuthFailed after VerifySessionUserId and PolicyInvalid after a session policy; 0x6A80 is PolicyInvalid on an object write; 0x6982 and 0x63Cx are AuthFailed on an authentication step. An unknown word is ChipSwUnknown. Applet 3.x may answer 0x6985 where 7.x answers 0x6A84 on a full memory; the map has no generation, so that case stays ConditionsNotSatisfied.

Parameters
commandThe command that was sent.
swThe status word.
Returns
Error::Ok for 0x9000, else the mapped error.
