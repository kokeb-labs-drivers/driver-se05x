# SE05X Driver API reference {#mainpage}

The classes, types and registers of the SE05X driver, generated from the headers in `inc/`.

Start with se05x::SE05X, the driver, and se05x::I2cInterface, the base of the port you write. Errors are
se05x::Error inside se05x::Result; the configuration is se05x::Config.

The guides, with examples that compile, are on the documentation site: <a href="../">SE05X Driver
documentation</a>.
