Detailed Description

The codecs (Codec<C>) of the commands of the groups Desfire and I2cm.

Copyright
Copyright (c) 2026 The driver-se05x authors. SPDX-License-Identifier: MIT

Layouts: AN12543 Rev 4.5 sections 4.16 (MIFARE DESFire, AES-128 EV2 S-mode) and 4.18 (I2C controller). The DESFire P2 values are those of Table 29 (FIRST_PART1 53, FIRST_PART2 12, NONFIRST_PART1 54, NONFIRST_PART2 13); the summary table 342 swaps two of them and is not followed (the middleware agrees with Table 29). The DESFire commands share one argument type: a field a command does not use must stay 0 or empty, so nothing is silently ignored.
