Detailed Description

ImportExternalObject: 80 06 00 00 <envelope> 00 (AN12543 Table 124; Le 00 asks for the receipt, whose length the decoder checks). The envelope is the whole payload: TLV[TAG_IMPORT_AUTH_DATA] TLV[TAG_IMPORT_AUTH_KEY_ID] 4 bytes TLV[TAG_1] wrapped write command, in that order (built by the ECKey layer). The answer is the 8-byte receipt, not a TLV (Table 125). NXP asks to be contacted before this command is used (AN12543 p. 88).
