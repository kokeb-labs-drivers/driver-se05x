Detailed Description

Handling of secrets: Zeroize(), SecretBuffer<N> and the constant-time compare ct::Equal().

The public surface is frozen; the bodies below are small and complete so that every layer can use them, and their tests and mutants cover them (compiler-barrier proof for Zeroize, timing-model mutant for Equal, S-01 and S-08).

Every secret the library holds, even for one call, lives in a SecretBuffer (S-01): it is wiped on every exit path by its destructor. A MAC, cryptogram, receipt, freshness value or PIN-like secret is compared only with ct::Equal(); memcmp is forbidden in inc/ (S-08).

The UserID rules of S-14 live here too, so every layer that writes or opens a UserID object applies the same ones: userid::CheckCredential() refuses the infinite attempt counter (the default, AN12543 Table 120 TAG_MAX_ATTEMPTS: 0 means unlimited) and lengths outside the generation's range, and AttemptLimiter counts failed authentications on the host so a loop cannot burn the chip's own counter.
