Detailed Description

template<typename Op>
class se05x::irreversible::Plan< Op >

The dry run of operation Op: what it would do, built without sending anything.

Only Operations<P> creates a prepared plan; the default value is not prepared and every operation refuses it with IrreversibleNotConfirmed.
