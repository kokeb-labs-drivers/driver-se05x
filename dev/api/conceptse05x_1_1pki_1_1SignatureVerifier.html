Detailed Description

A signature verifier: Supports(type) says which key types it verifies, and VerifySignature(type, public_key, digest, raw) verifies the fixed-width r || s over the digest: Ok valid, Mismatch invalid, InvalidKey a key that is not a valid point, Failed.
