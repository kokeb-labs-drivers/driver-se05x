Outcome of one I2C transaction; the port reports what happened, the link decides.

Enumerator
Ok 

The transaction completed.

Nack 

The target did not acknowledge: not ready yet, or absent.

Timeout 

The transaction did not complete in the port's own bound.

BusError 

Arbitration lost or a framing error.

BusStuck 

SCL or SDA held low (errata I2C.1): only a power cycle clears it.
