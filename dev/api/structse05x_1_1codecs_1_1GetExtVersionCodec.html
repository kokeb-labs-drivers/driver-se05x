Detailed Description

GetExtVersion: 80 04 00 21 00; answer: TLV[TAG_1] with 37 bytes, the VersionInfo and the 30-byte extended feature bitmap (AN12543 4.20.1). The reply keeps the 30 bitmap bytes.
