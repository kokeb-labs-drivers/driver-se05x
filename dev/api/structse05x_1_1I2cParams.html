Detailed Description

The I2C_PARAMS byte of the PERSO applet (tag 0x800E): chip-side bus and protocol settings.

Read-only in the public surface; a write is irreversible-class (S-10) because a wrong protocol leaves the chip unreachable from this host build. Settings take effect after the next chip reset.
