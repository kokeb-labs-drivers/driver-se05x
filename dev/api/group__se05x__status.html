enum class se05x::Error : uint8_t
strong

Why a call failed. Values 0 to 9 are the base set every driver of the org shares, 16 and up are specific to this chip family.

Enumerator
Ok 

The call succeeded.

NotInitialized 

Open() has not succeeded, or Close() ran since.

InvalidArgument 

An argument or Config field is out of range; nothing was sent.

Bus 

The I2C port failed (arbitration lost, hook returned a bus error).

Timeout 

A bounded wait ended: block waiting time, WTX budget or command timeout.

DeviceIdMismatch 

The chip is not the expected family or applet.

Crc 

A T=1 frame failed its CRC16 and the retry budget is spent.

Busy 

A command is in flight; one command at a time (errata I2C.1).

DeviceFault 

The chip reported an internal error (SW 0x6F00 and friends).

Unsupported 

The capability gate refuses the command for this chip or configuration.

BufferTooSmall 

A caller buffer, a frame or a response budget is too small; nothing was lost.

WrongState 

Locked applet, SCP required, no session, or an object of another class.

Nack 

The chip did not acknowledge its address (not ready, or absent).

BusStuck 

SCL or SDA held low; only a power cycle clears errata I2C.1.

TransportDead 

The recovery ladder is exhausted; the link is closed.

FrameError 

A T=1 frame is malformed (NAD, PCB, length, block sequence).

Resynced 

The link resynchronised: the command is not repeated, the caller re-authenticates.

NeedsReselect 

The applet must be selected again before the next command.

ObjectNotFound 

No object with that id (SW 0x6A82).

ObjectExists 

An object with that id exists.

PolicyDenied 

The object policy does not allow this operation (SW 0x6986 or 0x6982).

PolicyInvalid 

A policy was refused: by the builder or by the chip (SW 0x6A80 on creation).

AuthFailed 

Authentication failed; attempts_left is in the details when known.

AuthLocked 

The authentication object is blocked or the host-side attempt limit is reached.

ConditionsNotSatisfied 

SW 0x6985 with a context that has no better name.

MemoryFull 

No room for the object (SW 0x6A84, or 0x6985 on applet 3.x).

SecureChannelError 

A MAC, cryptogram, padding or counter check failed; the channel is closed.

AttestationInvalid 

Attestation freshness, timestamp or signature check failed.

Counterfeit 

The unique id or certificate chain does not match the expected device.

IrreversibleNotConfirmed 

An irreversible operation was called without its confirmation.

ChipSwUnknown 

A status word this driver has no mapping for (see Detail::sw).

CryptoFailure 

The crypto port failed or refused a key handle.

NotImplemented 

Not part of this version; no call returns it today.

ThroughputLimited 

SW 0x66A6: the chip refuses every command until it is reset (APDU budget, S-17).
