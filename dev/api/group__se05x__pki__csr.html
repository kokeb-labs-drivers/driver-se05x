Concepts

concept  se05x::pki::CsrSigner
 A signer: Algorithm() names the signature algorithm, and Sign(input, signature) signs (for ECDSA input is the digest and the result is the DER ECDSA-Sig-Value; for Ed25519 input is the message and the result is 64 bytes) and returns the length written.
