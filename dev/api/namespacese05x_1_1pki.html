Concepts

concept  CsrSigner
 A signer: Algorithm() names the signature algorithm, and Sign(input, signature) signs (for ECDSA input is the digest and the result is the DER ECDSA-Sig-Value; for Ed25519 input is the message and the result is 64 bytes) and returns the length written.
 
concept  SignatureVerifier
 A signature verifier: Supports(type) says which key types it verifies, and VerifySignature(type, public_key, digest, raw) verifies the fixed-width r || s over the digest: Ok valid, Mismatch invalid, InvalidKey a key that is not a valid point, Failed.
 
concept  DigestPort
 A hash function: the crypto port's Hash hook (every CryptoPort satisfies it).
