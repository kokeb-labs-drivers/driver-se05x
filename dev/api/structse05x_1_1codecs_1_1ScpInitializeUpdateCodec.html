Detailed Description

ScpInitializeUpdate (AESKey session): GP INITIALIZE UPDATE 80 50 00 00 <Lc> <host challenge> 00, KVN 00 (AN12543 4.5.3.1); the host challenge is 8 bytes (S8) or 16 (S16). The answer is not TLV: key diversification data (10), key information (3), card challenge, card cryptogram and an optional 3-byte sequence counter; it is kept raw in the reply.
