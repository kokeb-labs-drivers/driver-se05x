◆ ScpPolicy

enum class se05x::ScpPolicy : uint8_t
strong

When the library opens a platform SCP03 channel (S-13).

Enumerator
Auto 

Open one when the chip requires it; report a plain bus in Capabilities otherwise. The requirement is read from ReadState, which is not authenticated: a host on the bus can make Auto skip platform SCP03 (the facade then fails closed). Use Require for a root of trust.

Require 

Open one always; Open() fails when it cannot.

Off 

Never; refused with WrongState when the chip requires it.

◆ kMaxApduPayload

constexpr std::size_t se05x::kMaxApduPayload = 1024U
inlineconstexpr

Largest command or response payload of one APDU when the command sets no lower limit: the applet's 1024-byte internal buffer (AN12543 2.2 p. 3). Its APDU buffer is 270 bytes (wire::kApduBuffer); commands with their own limit (AEAD one-shot 888, EdDSA 940 or 919) check it in their codec.

◆ kMaxPlainCommandApdu

constexpr std::size_t se05x::kMaxPlainCommandApdu = 4U + 3U + kMaxApduPayload + 2U
inlineconstexpr

Largest plain command APDU a codec writes: header (4), extended Lc (3), a data field as large as the internal buffer (kMaxApduPayload) and an extended Le (2). A 940-byte EdDSA verify input is a 1028-byte plain APDU (AN12543 4.10.2.2 p. 104).

What one secure-messaging layer adds at most: ISO/IEC 9797-1 method 2 padding (up to 16 bytes), the 8-byte C-MAC and a short Lc that becomes extended (2 bytes).
