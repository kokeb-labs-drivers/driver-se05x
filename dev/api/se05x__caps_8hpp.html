Detailed Description

What a chip can do: the Capabilities record Device::Open() fills from the chip.

Frozen contract. The driver never trusts a part name: Capabilities is derived from the applet version and AppletConfig of the select response, the extended feature bits (applet 7.x), the OEF id of the card identification data and, with Config::probe_capabilities, two probes (ambiguities A4, A5). The derivation and the command gate are in se05x_gate.hpp; this file is only the data.
