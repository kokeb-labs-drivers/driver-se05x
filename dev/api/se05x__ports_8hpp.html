Detailed Description

The ports of the SE05X driver: I2C bus, clock, crypto with key handles, reset and log, and the Ports set that binds them.

Copyright
Copyright (c) 2026 The driver-se05x authors. SPDX-License-Identifier: MIT

Frozen contract. The library calls no SDK. It calls hooks on classes you derive from the CRTP bases below; each base is checked by a concept that matches every hook with its exact signature, noexcept included (KB-CPP20-006).

Port Required Hooks
Bus (BusInterface<D>) yes bool EnsureInitialized(), BusStatus Write(uint8_t addr7, ByteSpan), BusRead Read(uint8_t addr7, MutableByteSpan); optional uint32_t MaxClockKhz() const
Clock (ClockInterface<D>) yes uint64_t NowUs() (monotonic microseconds since boot that never wrap in the life of the device: every deadline is an absolute 64-bit time, so a widened 32-bit counter must count its wraps), void DelayUs(uint32_t) (at least the time asked)
Crypto (CryptoInterface<D>) yes key handles: ImportKey, ReleaseKey, AesCmac, AesCbc, GenerateP256, EcdhP256, EcdsaP256Sign, EcdsaP256Verify, Hash, Random
Reset (ResetInterface<D>) no bool Reset() (must really reset the chip: ENA on an I2C-only SE050/SE051, RST_N on the SE052), bool PowerCycle(), bool SetEnable(bool) (ENA pin; false on a part without one)
Log (LogInterface<D>) no void Log(const LogRecord&)

A call that needs a port the user did not provide does not compile: the member is constrained on Ports::kHasReset or kHasLog. A missing ResetInterface removes the power-cycle rung of the recovery ladder (S-06) and Device::PowerCycle().

What the bus port must do. Write never gets an empty span, and the library never sends an address-only frame (errata I2C.2). Read returns the bytes read and a BusStatus: Nack while the chip is not ready (the link polls), Timeout, BusError (arbitration, framing) and BusStuck (SCL or SDA held low) are distinct, because only the last one needs a power cycle (errata I2C.1). The port moves bytes: it never retries and never frames. Keep SDA and SCL high around a reset (errata I2C.3) and change SCL before SDA with the data sheet's margin (errata I2C.4).

What the crypto port must do. Keys are handles (KeyRef): a hardware key store or a library context sits behind them, and the library never keeps raw key bytes beyond one operation (S-16). ImportKey consumes the bytes (the caller wipes its copy with Zeroize()); ReleaseKey frees the handle and must wipe whatever the port holds. Only operations the secure channels need are here (design section 4); there is no signing with a long-term key on the host.
