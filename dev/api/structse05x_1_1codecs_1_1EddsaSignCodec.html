Detailed Description

EddsaSign: 80 03 0C 09 TLV[TAG_1] key TLV[TAG_2] A3 TLV[TAG_3] message (1 to 940 bytes; 919 in a UserID session, which the device checks), Le; answer TLV[TAG_1] 64 bytes r || s, each reversed (AN12543 4.10.1.2, 7.1). The reply holds the signature in RFC 8032 order.
