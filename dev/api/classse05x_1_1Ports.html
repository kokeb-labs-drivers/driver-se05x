class se05x::Ports< B, C, K, R, L >

The set of ports one Device works through: references to the bus, the clock and the crypto port, and, when given, the reset and log ports.

Ports<Bus, Clock, Crypto> is the smallest set. Ports<Bus, Clock, Crypto, Reset, Log> adds the optional ones; pass Absent for the one you leave out (Ports<B, C, K, Absent, MyLog>). The set owns nothing: every port must outlive it.
