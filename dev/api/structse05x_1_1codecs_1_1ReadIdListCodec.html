Detailed Description

ReadIdList: 80 02 00 25 TLV[TAG_1] 2-byte offset TLV[TAG_2] type filter (FF for all), Le; answer TLV[TAG_1] MoreIndicator TLV[TAG_2] the 4-byte ids (AN12543 Tables 142, 143; Table 56: 01 NO_MORE, 02 MORE, the text of p. 94 says the reverse and is not followed).
