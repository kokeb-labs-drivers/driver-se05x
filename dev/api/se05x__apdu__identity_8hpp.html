Detailed Description

The codecs (Codec<C>) of the commands of the groups Identity, Session and Management.

Copyright
Copyright (c) 2026 The driver-se05x authors. SPDX-License-Identifier: MIT

Layouts: AN12543 Rev 4.5 sections 4.4 to 4.6 and 4.16 (applet 7.x), AN12413 Rev 2.12 sections 4.4 to 4.6 and 4.19 (applet 3.x), GlobalPlatform Card Specification (GET DATA, INITIALIZE UPDATE, EXTERNAL AUTHENTICATE). Three layouts are derived, not printed in the specifications, and say so where they are: the GET DATA of the card identification (tag DF28; AN13030 pp. 227-228 show only the answer), of the CPLC (tag 9F7F) and of the card manager garbage collection (tag DF25; AN13030 p. 262 shows only the answer). Those three go to the card manager, so the device selects it first and selects the IoT applet again afterwards.
