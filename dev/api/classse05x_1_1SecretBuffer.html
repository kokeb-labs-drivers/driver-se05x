Detailed Description

template<std::size_t N>
class se05x::SecretBuffer< N >

Up to N secret bytes, wiped when the object dies, is wiped, or is reused.

Not copyable and not movable: a secret has one home. Span() gives the stored bytes; keep the view no longer than the buffer.
