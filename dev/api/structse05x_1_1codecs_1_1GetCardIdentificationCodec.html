Detailed Description

GetCardIdentification: GP GET DATA 80 CA 00 FE 02 DF 28 00 to the card manager (derived: the command is not printed; AN13030 pp. 227-228 show the answer FE L DF28 L {01 0C config id ...}). The OEF id is bytes 2 and 3 of the 12-byte configuration id.
