◆ Reason

enum class se05x::pki::Reason : uint8_t
strong

Why a PKI call failed, precisely; Detail::step carries it.

Enumerator
Ok 

No failure.

Truncated 

An element runs past the end of its input.

HighTagNumber 

A tag number above 30 (multi-byte tag): not used by this profile.

IndefiniteLength 

The length byte 0x80: BER, never DER.

NonMinimalLength 

A length in more bytes than it needs.

LengthTooLarge 

A length above der::kMaxLength, or a reserved length form.

TrailingData 

Bytes after the last element where none may follow.

TooDeep 

Nesting deeper than der::kMaxDepth.

UnexpectedTag 

Another tag than the structure needs.

BadInteger 

An empty, non-minimal, negative or too large INTEGER.

BadBoolean 

A BOOLEAN that is not one byte 0x00 or 0xFF.

BadBitString 

A BIT STRING with a bad unused-bit count or a non-zero pad bit.

BadOid 

An OBJECT IDENTIFIER that is empty, too long or not minimal.

BadString 

A string type the layer does not accept, or a bad character.

BadTime 

A UTCTime or GeneralizedTime that is not of the RFC 5280 form.

BadNull 

A NULL with content.

UnsupportedVersion 

A certificate that is not X.509 v3, or a CSR that is not v1.

UnsupportedAlgorithm 

A signature or key algorithm this layer does not handle.

UnsupportedCurve 

An EC public key on another curve than P-256 or P-384.

BadPublicKey 

A public key of the wrong length or form (compressed, no 04).

AlgorithmMismatch 

The two signature algorithms differ, or key and hash do not pair.

UnknownCriticalExtension 

A critical extension this layer does not process.

DuplicateExtension 

The same extension twice.

BadExtension 

An extension whose value does not parse.

UniqueIdPresent 

An issuerUniqueID or subjectUniqueID (not supported).

BadName 

An empty issuer, or a Name that is not well formed.

BadSignatureValue 

A signature value that is not a valid ECDSA-Sig-Value.

NameMismatch 

A certificate's issuer is not its issuer's subject.

SignatureInvalid 

A signature does not verify.

NotYetValid 

The time is before notBefore.

Expired 

The time is after notAfter.

NotCa 

An issuing certificate without basicConstraints cA TRUE.

KeyCertSignMissing 

An issuing certificate whose key usage lacks keyCertSign.

PathLengthExceeded 

More intermediates than a pathLenConstraint allows.

ChainTooLong 

More than kMaxChain certificates.

NoTrustAnchor 

No trust anchor has the subject the chain needs.

LeafKeyUsageMissing 

The end-entity certificate lacks a required key usage.

LeafIsCa 

The end-entity certificate is a CA and the options refuse it.

CurveNotSupported 

The verifier cannot verify on this curve.

CryptoFailure 

The crypto port or the verifier failed.

NoTime 

No time was given (0): the validity check cannot run.

EmptyInput 

An empty chain, name or input where one is needed.

BufferTooSmall 

The output buffer is too small.

InvalidInput 

A builder argument is out of range (length, character set).

TooManyEntries 

More attributes or alternative names than the builder holds.

SignerFailed 

The signer (chip or port) failed.

SignerOutputInvalid 

The signer returned a signature that does not parse.

ObjectTooLarge 

A certificate that does not fit one WriteBinary command.

PolicyAllowsWrite 

A storage policy that lets someone change the certificate.

ReadBackMismatch 

The object read back differs from what was written.

NotACertificate 

A stored object that is not exactly one certificate.
