Detailed Description

An attestation key the caller trusts: the chip object that signs and its public key from a trusted source. Build one with TrustAttestationKey().

Where the public key comes from decides what an attestation proves. For the vendor key (ReservedId::RootOfTrustKey), take it from the vendor certificate after the certificate chain was verified (the se05x::pki layer); for a facade AttestKey, from the factory record made when it was provisioned. Reading it from the same chip proves nothing.
