Detailed Description

The codecs (Codec<C>) of the commands of the groups Ec, Rsa, Cipher, Aead, Mac, Digest and Kdf.

Copyright
Copyright (c) 2026 The driver-se05x authors. SPDX-License-Identifier: MIT

Layouts: AN12543 Rev 4.5 sections 4.10 to 4.13, 4.16 and 4.17 (applet 7.x) and AN12413 Rev 2.12 sections 4.10 to 4.14 (applet 3.x; ECDAA). INS is INS_CRYPTO (0x03) throughout. Byte order (AN12543 section 7): an EdDSA signature is given and returned in RFC 8032 order, r and s each reversed on the wire; a Montgomery peer key in RFC 7748 order is reversed on the wire, and a plain Montgomery shared secret is reversed back. A failed verification of an authenticated decryption or a MAC (Result 02 with SW 0x9000) is AuthFailed, and the output buffer is zeroed.
