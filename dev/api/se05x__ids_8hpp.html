Detailed Description

Object identifiers, the reserved ids and the secure object classes of the applet.

Copyright
Copyright (c) 2026 The driver-se05x authors. SPDX-License-Identifier: MIT

Frozen contract. An ObjectId is a 4-byte identifier, big endian on the wire. A caller makes one with MakeUserObject(), which refuses the range the applet reserves (0x7FFF0000 to 0x7FFFFFFF, AN12543 3.2.4.1 p. 10) and 0xE0000000 and up: 0xF0000000 and up is where NXP pre-provisions keys (AN12436), and the whole of 0x80000000 and up is the NXP reserved area of the SE052F (AN13904 Table 1, p. 7). AN12543 reserves neither, so the 0xE range is a choice for every part (docs/ambiguities.md A27); 0x80000000 to 0xDFFFFFFF stays open for the SE050 and SE051, and AN13904 advises 0x00000000 to 0x7BFFFFFF for in-field objects. The reserved ids have names in ReservedId, and IsNxpOwned() marks the ones the driver never writes (AN12413 reserved objects, AN12436 pre-provisioned objects; the middleware's reserved id list for the 0x7FFF02xx values).
