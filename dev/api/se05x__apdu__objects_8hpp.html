Detailed Description

The codecs (Codec<C>) of the commands of the groups ObjectWrite, ObjectRead, Curve and CryptoObject.

Copyright
Copyright (c) 2026 The driver-se05x authors. SPDX-License-Identifier: MIT

Layouts: AN12543 Rev 4.5 sections 4.7 to 4.9 (applet 7.x) and AN12413 Rev 2.12 sections 4.7 to 4.9 (applet 3.x). TLV order in a command is the order of the tables (AN12543 4.1.5). Every key length is checked against the curve before anything is sent (errata JOS.1: an EC key of the wrong length resets the chip). Edwards and Montgomery keys are taken in RFC 8032 / RFC 7748 order and reversed on the wire (AN12543 section 7); ReadObject returns what the chip stores, so a reader of such a public key reverses it with wire::ReverseBytes.
