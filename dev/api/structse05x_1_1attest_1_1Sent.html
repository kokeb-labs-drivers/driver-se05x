ByteSpan se05x::attest::Sent::signed_tlvs

Format 2: the TLVs of the answer before the signature, byte for byte as the chip returned them. When given, the signed message is H(command) followed by these bytes (AN12543 Table 128 p. 91); when empty, the verifier rebuilds them with the 82 xx xx length form (A21).
