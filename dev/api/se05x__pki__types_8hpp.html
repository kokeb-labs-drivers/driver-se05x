Detailed Description

The vocabulary of the optional PKI layer (se05x::pki): reasons, key and signature types, key usage bits, calendar time, object identifiers and limits.

The PKI layer is opt-in: nothing else in the library includes its headers, and se05x.hpp does not either. Include se05x_pki.hpp for all of it.

Every fallible call of the layer returns a Result<T>. On failure Detail::layer is Layer::Pki and Detail::step holds the precise Reason (ReasonOf() reads it back), while Result::error is the coarse Error of ErrorOf(): InvalidArgument for a malformed input or a bad builder argument, Unsupported for a well-formed input this layer does not handle, AttestationInvalid for a certificate or signature check that failed, BufferTooSmall and CryptoFailure. A failure from the device keeps the device's own details.
