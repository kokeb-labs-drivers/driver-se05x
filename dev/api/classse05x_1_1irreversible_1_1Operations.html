Create a binary object that can never be changed or deleted: the policy must grant neither Write nor Delete to any authentication object; the data is written in the creating command.

Parameters
idThe new object (a user id).
policyThe policy, built for the chip's generation.
data1 to kMaxImmutableBytes bytes; keep them unchanged until Apply().
Returns
The plan; InvalidArgument (reserved id, empty or too much data, a policy that grants write or delete: use Device::WriteBinary, it is not irreversible); PolicyInvalid (another generation); the state errors.
