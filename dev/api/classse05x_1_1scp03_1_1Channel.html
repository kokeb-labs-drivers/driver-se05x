template<PortSet P, ApduTransport T>
class se05x::scp03::Channel< P, T >

Template Parameters

TThe lower transport, usually t1::Link<P>; never a UserID session (S-14).

template<PortSet P, ApduTransport T>
Result< void > se05x::scp03::Channel< P, T >::Open ( const ChannelParams &  params)
noexcept

Run INITIALIZE UPDATE and EXTERNAL AUTHENTICATE and derive the session keys; for an AESKey session, CreateSession first.

Parameters
paramsThe key handles and the level.
Returns
Ok, InvalidArgument (missing key handle, value out of range, an AESKey session without a credential or with AES-256), WrongState (already open), AuthLocked (the host-side attempt limit is reached; nothing sent), AuthFailed (the chip refused; counted), SecureChannelError (bad card cryptogram or malformed answer; counted), CryptoFailure, ThroughputLimited or a transport error.
