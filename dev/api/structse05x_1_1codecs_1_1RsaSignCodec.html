Detailed Description

RsaSign: 80 03 0C 09 TLV[TAG_1] key TLV[TAG_2] RSASignatureAlgo TLV[TAG_3] digest, Le; answer TLV[TAG_1] signature (AN12543 4.11.1.1). The digest length must be the algorithm's (derived: the specification does not say whether TAG_3 is the digest; the middleware sends it).
