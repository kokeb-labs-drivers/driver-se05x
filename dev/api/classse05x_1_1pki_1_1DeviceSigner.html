Detailed Description

template<PortSet P>
class se05x::pki::DeviceSigner< P >

A CsrSigner over a key pair inside the chip: ECDSASign with the precomputed digest (AN12543 4.10.1.1) or EdDSASign with the message (4.10.1.2, at most 940 bytes, 919 in a UserID session; not on SE052F). The private key never leaves the chip.

PThe port set of the device.
