Detailed Description

The capability gate: deriving Capabilities and deciding whether a command may be sent.

Copyright
Copyright (c) 2026 The driver-se05x authors. SPDX-License-Identifier: MIT

The public surface below is frozen; the tables and helpers are in se05x::gate::detail.

The gate refuses a command the chip's version, features, state or Config::held_commands do not allow before anything is sent (S-11), which also avoids errata JOS.1. The inputs are what the chip reports: the applet version and AppletConfig of the select response (AN12543 Table 8, AN12413 Table 40), the 30 extended feature bytes of applet 7.x (AN12543 Table 9) and the OEF id (AN12436 Table 2 for SE050, AN12973 Table 4 for SE051, the SE052 data sheet ordering table for SE052F). A part name is never trusted: an OEF id that contradicts the applet generation is DeviceIdMismatch.

Command availability per generation: a command printed only in AN12543 is applet 7.x, one printed only in AN12413 is applet 3.x. Applet 6.x has no specification in hand: it gets only the commands both documents print (the conservative intersection).

Per variant: SE052F has no EdDSA, no Montgomery curves, no DES, no ECDAA and no MIFARE DESFire whatever AppletConfig says (SE052 data sheet; AN12543 3.13.2); SE050F refuses curves below 224 bits (FIPS 140-2 configuration).
