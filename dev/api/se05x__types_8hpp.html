constexpr bool se05x::kIrreversibleEnabled = false
 Whether the irreversible operations are compiled in (S-10): lifecycle locks, the platform SCP requirement, platform key replacement, feature changes, DeleteAll. The build flag SE05X_ENABLE_IRREVERSIBLE (define it to 1; absent or 0 means off) sets it; CMake sets the flag with the option of the same name, Kconfig with CONFIG_SE05X_ENABLE_IRREVERSIBLE. Members that perform an irreversible operation are constrained on this, so a default build cannot call them.

Detailed Description

Shared vocabulary of the SE05X driver: byte views, size limits, families, versions and Config.

Copyright

Frozen contract. Plain data with no platform dependency, so handlers, tests and tools can include it without the driver. Config{} holds the defaults of the design (docs/ambiguities.md names the knob of every open question); Validate() checks a configuration with no I/O.
