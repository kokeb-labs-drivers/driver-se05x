Detailed Description

Object attribute parsing and the check of a policy set read back from the chip.

Copyright
Copyright (c) 2026 The driver-se05x authors. SPDX-License-Identifier: MIT

The public surface below is frozen.

The attribute block (AN12543 3.2.4 Tables 3 and 4, applet 7.x; AN12413 3.2.4 Table 3, applet 3.x) is 14 fixed bytes, the policy set, the origin and, on 7.x only, a 4-byte version:

Bytes Authentication object Other object
0-3 identifier identifier
4 SecureObjectType SecureObjectType
5 authentication indicator (SetIndicator) authentication indicator
6-7 failed attempts counter minimum AEAD tag length (7.x)
8-11 session owner session owner
12-13 maximum attempts (0: unlimited) minimum output length (7.x)

The block carries no generation, so the parser tells the layout by its trailer: the policy set must parse exactly between byte 14 and the trailer of 5 (7.x) or 1 (3.x) bytes. The two cannot both parse, because a policy is at least 9 bytes and the trailers differ by 4. The policy set is the concatenation of policies L | auth id (4) | header (4) | extensions, L from 8 to 52. Derived from the documents; not verified against a chip.
