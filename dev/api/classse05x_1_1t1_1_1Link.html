◆ Open()

template<PortSet P>
Result< void > se05x::t1::Link< P >::Open ( )
noexcept

Bring the link up: drive ENA high when the set has a reset port, wait boot_wait_ms, read out a response an earlier host left (errata I2C.1), then within atr_poll_budget_ms exchange the interface soft reset (NXP: its response carries the ATR; GP: then the CIP request) and fix the flavour, the CRC order and the parameters. TransportFlavour::Auto tries the GP flavour for the first half of the budget, then the NXP flavour; a stale frame read at the start decides it at once. Works from every state but InFlight.

Returns
Ok; InvalidArgument (bad Config; nothing sent); Busy; Bus (the bus port failed, or EnsureInitialized() returned false); Nack (no write was acknowledged: no chip); BusStuck; Timeout, Crc or FrameError (no valid answer within the budget). On failure the link is Closed.

Result< void > se05x::t1::Link< P >::Recover ( Rung  from)
noexcept

Climb the recovery ladder from from upwards until a rung succeeds.

ResendBlock has nothing to resend outside a command and starts at Resync. Reselect is the layer above's rung: called with it, the link marks NeedsReselect and sends nothing; climbing past it from below (the soft reset failed) skips it.

Parameters
fromThe first rung to try.
Returns
Resynced (the resynchronisation succeeded and no reset is pending), NeedsReselect, TransportDead (the link is Dead), NotInitialized (closed), Busy or InvalidArgument.

Send one command APDU and read the response APDU.

Single flight: a call while one is in flight returns Busy. Chains over several I-blocks, answers waiting time extensions within the WTX budget, recovers within the ladder. Allowed in NeedsReselect (the layer above sends its SELECT this way); a success then leaves Idle.

Parameters
commandThe command APDU, 1 to kMaxCommandApdu bytes.
responseThe buffer for the response APDU (body and status word), at least 2 bytes.
command_classSelects the timeout of Config::timeouts.
Returns
The response length; or, with nothing sent, NotInitialized (closed), TransportDead (dead), Busy, InvalidArgument (empty or oversized command, a class that is not an enumerator) or BufferTooSmall (response buffer under 2 bytes); or, after the exchange, BufferTooSmall (the response did not fit; the link stays in step), FrameError (a response under 2 bytes), Timeout (command deadline or WTX budget: the next call resynchronises first), Resynced, NeedsReselect or TransportDead (the ladder ran; the command is not repeated), BusStuck (no reset port to power-cycle). After a Timeout the next call resynchronises first; when that needs more than the resynchronisation it returns NeedsReselect or TransportDead without sending its command.
