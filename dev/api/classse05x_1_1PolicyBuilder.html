Detailed Description

template<AppletGeneration G, ObjectClass C, Profile P = Profile::Strict>
class se05x::PolicyBuilder< G, C, P >

Builds the policy of one object of class C for applet generation G.

PolicyBuilder<AppletGeneration::V3, C> and PolicyBuilder<AppletGeneration::V7, C> are different types: a rule that does not exist in a generation does not compile for it. For() or ForAllOthers() starts a policy (one per authentication object, at most 8); Allow and Forbid act on the policy started last. A 7.x key agreement key should forbid derived output (POLICY_OBJ_FORBID_DERIVED_OUTPUT, AN12543 Table 63) unless the secret is meant to leave the chip.

constexpr auto kPolicy = PolicyBuilder<AppletGeneration::V7, ObjectClass::EcKeyPair>{}
.For(AuthObject{ObjectId{0x7FFF0001U}}) // or .ForAllOthers()
.Allow<Rule::Sign>().Allow<Rule::Attestation>()
.RequireSecureMessaging()
.Forbid<Rule::Write>().Forbid<Rule::Delete>().Forbid<Rule::Gen>()
.Build();
