Detailed Description

The data types of object and session policies: rules, profiles, Policy, SessionPolicy.

Copyright
Copyright (c) 2026 The driver-se05x authors. SPDX-License-Identifier: MIT

Frozen contract. A caller never assembles a policy from bytes: the only way to get a Policy is PolicyBuilder<Generation, Class, Profile>::Build() (declared in se05x_policy.hpp), and Policy::Bytes() is the only way out. The Strict profile is the one the facade uses (S-03): a key created with the default policy would keep ALLOW_WRITE, ALLOW_DELETE and ALLOW_GEN, so Strict demands that they are forbidden explicitly. Open needs a named OpenReason.
