Detailed Description

A validated object policy set: at most kMaxPolicyBytes bytes in the chip's format.

Only PolicyBuilder::Build() creates a non-empty one. The default value is empty and invalid (IsEmpty()); every command that takes a policy refuses an empty one with InvalidArgument.
