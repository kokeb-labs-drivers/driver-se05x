Detailed Description

Lifecycle preconditions as types: which authenticated session role a management command needs, and what its reply does to the channel.

Frozen contract and fully implemented (it is data). A management command that the chip accepts only in a session authenticated by a reserved object is refused by Device with Error::ConditionsNotSatisfied before anything is sent, unless the session role matches (design S-11). The role comes from the reserved authentication object the session was opened with (RoleOf(ObjectId)).
