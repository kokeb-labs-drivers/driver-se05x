constexpr bool se05x::attest::TimestampAfter ( const Timestamp &  now,
const Timestamp &  last 
)
constexprnoexcept

Whether timestamp now is strictly later than last: the transient part is strongly monotonic (AN12543 3.9 p. 42), so two verified answers never carry the same timestamp; an equal one is a replay. A last of all zero (no answer verified yet) accepts any timestamp.

Parameters
nowThe timestamp of the new answer.
lastThe timestamp of the previous verified answer from this chip, or all zero.
Returns
true when now > last, or last is all zero.
