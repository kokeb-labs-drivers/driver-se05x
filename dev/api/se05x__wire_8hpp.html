Detailed Description

Numbers read from the specifications: the two T=1 frame flavours, the S-block codes, the link defaults, the buffer sizes and the byte-order helper of the Edwards and Montgomery values (frozen constants).

Copyright
Copyright (c) 2026 The driver-se05x authors. SPDX-License-Identifier: MIT

Frozen: private helpers go in src/se05x_t1.ipp, not here. Sources: UM11225 Rev 1.2 (NXP flavour, pages 5-19), GPC_SPE_172 v1.0 (GP flavour, pp. 21-39), AN12543 Rev 4.5 (buffers, byte order), AN13904 p. 27 (WTX timeout). The CRC byte order of the NXP flavour is not stated in UM11225; it stays the model knob crc_swapped (ambiguity A10). No default key of any platform is in this repository.
