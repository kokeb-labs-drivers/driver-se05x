Detailed Description

The numeric constants of the IoT applet APDU interface and the maps from the abstract enumerations of se05x_device_types.hpp to their wire values.

Every number below is read from the applet specifications: AN12543 Rev 4.5 section 4.3 (applet 7.x; the tables are named next to each constant) and AN12413 Rev 2.12 section 4.3 (applet 3.x), which agree on every value used here except where a comment says otherwise. A wire value never leaks into the public API: the codecs call the *Wire() maps. A map returns false for a value the applet does not support (a "NOT SUPPORTED" row of the specification), and the codec refuses the command before anything is sent.
