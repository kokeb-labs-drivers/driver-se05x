Detailed Description

The typed policy builder.

Copyright
Copyright (c) 2026 The driver-se05x authors. SPDX-License-Identifier: MIT

The public surface below is frozen; the library adds the private state and the helpers in se05x::policy.

A policy cannot be assembled from bytes by the caller. A rule that is invalid for the object class in the applet generation fails to compile (Allow<Rule::Sign>() on a BinaryFile builder). Build() applies the chip's own validation (AN12543 3.7.1: one policy is 9 to 53 bytes, a length, a 4-byte authentication object id, a 4-byte access rule header and the extensions in header bit order; unique authentication object ids; at most kMaxPolicyBytes in all) and the checks of the profile (S-03). The rule tables are AN12413 Table 11 (applet 3.x) and AN12543 Table 15 (applet 7.x); the bit values are AN12413 Table 50 and AN12543 Table 63, which the middleware's se05x_const.h agrees with.

Applet 6.x: no document gives its policy table or bit values (the middleware dropped 6.x), so a 6.x builder compiles with the 3.x rule table but Build() refuses it with Unsupported. Nothing is sent to a 6.x chip with guessed policy bits.
