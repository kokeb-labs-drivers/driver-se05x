Detailed Description

VerifySessionUserId: 80 04 00 2C TLV[TAG_1] UserID value, 1 to 16 bytes (AN12543 Table 82; SE050 accepts 1 to 16 bytes, SE051 4 to 16; the chip refuses a wrong length with 0x6985).
